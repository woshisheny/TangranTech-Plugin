## 造物匣破坏掉绿玻璃板——根因与极简修复

- 现象：破坏造物匣（mat_generators，130 台）必掉 1 块绿色玻璃板。
- 排查：全搜绿玻璃板构造点 → menus.yml 装饰 0 号槽 GREEN_STAINED_GLASS_PANE；
  交叉比对 output 槽与装饰槽无重叠；Slimefun（f172239 存储版）反编译确认破坏掉落 =
  dropItems(input+output+extraFunctionalSlots)；**TTMaterialGenerator.extraFunctionalSlots()
  返回 statusSlot=0（mat_generators.yml 全部 `status: 0`）→ 0 号槽的装饰板被整块掉出**。
  `getStatusSlot()` 全库 0 调用方——「状态槽」除被掉落外什么也没干。
  （附：block-storage.db 里 TR_MGZJ 35 号槽曾有 lime 玻璃板 ×12，是玩家 shift-click
  塞进输出槽的杂物，破坏时随输出槽返还，属正常行为，另案不处理。）
- 修复（用户拍板的极简方案）：0 号槽位就让它当机器装饰板——
  删 TTMaterialGenerator 的 statusSlot 字段/getStatusSlot/extraFunctionalSlots 覆盖，
  构造器去掉 statusSlot 参数；MaterialGeneratorsLoader 不再读 `status`。
  0 号槽回到 menu.items 注册路径（装饰板 + 空点击处理器），不进任何掉落列表。
- 曾写的「输出槽白名单过滤 + 0 输入机器拦 shift」复杂方案按用户意见整体回退。
- 构建通过：TangranTech-2.1.0-standalone.jar 7,404,570 字节（22:52）。
  改动 2 文件 +12/−23。未提交，等实测。
