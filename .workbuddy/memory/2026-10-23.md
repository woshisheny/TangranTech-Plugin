## 配方预览按钮点击无效 → 事件优先级修复

**现象**：指南里「多物品输入/输出」绿色按钮出现，但点击无反应。

**根因（javap 反编译实证）**：
1. Slimefun 指南菜单点击由内嵌 `me.mrCookieSlime.CSCoreLibPlugin.general.Inventory.MenuListener` 处理，
   无参 `@EventHandler` = NORMAL 优先级；
2. 其 `handleEvent` 字节码证实：槽位 MenuClickHandler 返回 false → `event.setCancelled(true)`；
   「多物品」按钮是非 SlimefunItem 的玻璃板，走空 handler 恒 false → 事件被取消；
3. 我们的 `RecipePreview.ClickListener` 原为 NORMAL + `ignoreCancelled=true`：Slimefun 先启用先注册，
   同优先级先执行，事件到我们这已被取消 → 整个被跳过。

**修复**：`RecipePreview.java` 监听器改 `EventPriority.LOW`（对齐 RSC RecipeViewListener）；
加两条验证日志（成功打开 / 定位机器失败时打印槽 16 内容，便于排查 JEG 改版布局）。

**顺带核实**：槽 16 假设正确——WebFetch Slimefun4 源码 `SurvivalSlimefunGuide.displayItem`：
`menu.addItem(16, output, ...)`（物品页槽 16 = 机器配方产出物）；displayRecipes 的输入/输出
交替铺在 36-44 / 45-53。

**沉淀**：MEMORY.md 铁律⑦（指南/ChestMenu 内监听点击必须 LOW）。

## 配方预览「只有三行」→ ChestMenu 自动推断尺寸修复

**现象**：点击按钮后能跳转预览界面，但界面只有 27 格（三行）。

**根因（javap 反编译实证）**：`ChestMenu(String)` 单参构造把 `size` 置 **-1**（自动推断模式），
`getSize()` = **9 × ceil(已登记物品数 / 9)**——预览界面刚建好只登记了少量背景物品就被定型成 27 格。
真实机器界面走 `BlockMenuPreset` 显式尺寸所以无此问题。

**修复**：`RecipePreview.buildMenu` 把尺寸计算提到创建之前，改用双参
`new ChestMenu(title, size)`（反编译确认其调用 setSize）。

## 异步主线程检查报错修复（投影未生效的根因）

实测日志：放置核心后 `AsyncCatcher「failed main thread check: getNearbyEntities」`，栈顶是
`TickerTask → CompletableFuture.AsyncRun → ForkJoinPool worker`——**Slimefun 机器 tick 跑在异步线程**，
tryStart 里的 getNearbyPlayers / spawnEntity / findAdoptable 全被主线程检查拦截 → 投影生成中断。

修复：SuperBlocks 加 `runSync(Runnable)`（主线程内联、异步则 runTask 调度），包住
notice / spawnProjectiles / removeProjectiles 的全部实体操作。RSC 原版正是用
Asynchronized.runTask 包住实体操作——对齐。

**沉淀铁律⑧**（MEMORY.md）：机器 tick 异步，实体/玩家操作必须 runSync；方块读取与
StorageCacheUtils 读写异步可用。

## 成形后不生产 → 建档扫描缺陷修复

症状：多方块机器搭建完成后放材料不生产。

根因（两缺陷叠加）：① 建档初始扫描跑在异步线程（机器 tick 异步），异步读方块有陈旧/异常风险；
② **逐格 dirty 检测只覆盖建档后的方块事件**——「先搭外壳、最后放核心」的常见流程里，外壳方块的
事件全部发生在实例存在之前被丢弃，初始扫描成了唯一判定，读错一格即永久未成形且无自愈途径。

修复：
- tryStart 的注册+初始扫描移到主线程（runSync）；
- 未成形实例每 40 tick 全量重扫自愈（fullRescan，同步刷新投影发光态，状态迁移与 processDirty 同语义）；
- 仍不成形时每 5 次重扫（约 200 tick）打一条诊断日志（id @坐标 已就位N/M），便于实机定位缺失格。

产物：TangranTech-1.0.0-standalone.jar（1,390,254 字节，03:46）。
